# Stokerjack ハードウェアデータ

60キー・全1u配列向けの基板外形とプレートデータです。DXF・STLの寸法単位はmmです。STLを読み込むときもmmを指定してください。

|---|---|---|

| アクリル製スイッチプレート | [共通形状DXF](acrylic/switch-plate-common-mm.dxf) | 左右共通2枚、1枚118.25 × 99.20 mm、板厚1.5 mm案 |
| アクリル製ミドルプレート | [共通枠DXF](acrylic/middle-frame-common-mm.dxf) | 1層につき左右共通2枚、1枚115.25 × 99.20 mm、枠幅3 mm |
| 3Dプリント製スイッチプレート | [左STL](switch-plate-stl/switch-plate-left.stl) / [右STL](switch-plate-stl/switch-plate-right.stl) | 各1枚、約112.25 × 93.20 × 1.50 mm |
| スイッチ穴の寸法確認 | [テスト片STL](switch-plate-stl/switch-fit-test-14.0-14.1-14.2.stl) | 1枚、60 × 22 × 1.50 mm |

ファイル単体はGitHubのダウンロードボタン、全体はリポジトリの **Code → Download ZIP** から取得できます。

## 基板外形

2026-10-26の60キー・OST砲弾型LED基板の外形Gerberから抽出しました。DXFは80本の直線・円弧を1本の閉じたポリラインに接続し、元の座標と縮尺を保持しています。外形線の中心を基板境界としています。

範囲はXが10.05〜294.75 mm、Yが−149.50〜−55.29062 mmです。収録対象は外周と外周につながる切り欠きです。取付穴・スイッチ穴・銅箔・シルクは含みません。

## アクリル加工

2026-10-15に作成した、中央側の縁を補強したプレート案です。DXFの `CUT` レイヤーを原寸で全貫通加工します。左右には同じ部品を使い、右側は表裏を返して配置します。中央の電池・マイコン部分は開放です。

- 上板はスイッチ穴30個を持ち、中央側の縁幅は4.5 mmです。
- ミドルプレートはコの字形の挟み込み枠です。板厚と積層数は、使うケースと部品高さに合わせて決めてください。
- 固定ネジ穴はありません。底板で枠を支え、ケース側で締結と位置決めを行う構成です。
- 上板の中央側がダイオードやUSB-C用のCC抵抗の上にかかるため、組立時の高さを確認してください。

アクリル案の実物適合・剛性は未検証です。基板外形は2026-10-26版、アクリルは2026-10-15案なので、加工前に使用する基板・ケースと照合してください。

## 3Dプリント

2026-10-14の60キー基板のスイッチ中心から作成したプレートです。左右各30キー、スイッチ穴は14.1 mm角です。左右それぞれのSTLを1枚ずつ、平らな面をベッドに置いて印刷します。

先にテスト片を印刷してください。切り欠きを左上にしたとき、穴は左から14.0 / 14.1 / 14.2 mm角です。本体STLには14.1 mmの穴を採用しています。使用するスイッチが入り、爪が掛かることを確認してください。

積層0.15 mm・充填100%・サポートなしが試作時の設定案です。厚さ1.5 mmの薄板で、実際のはめ合いと剛性は未検証です。アクリル案とは外形寸法が異なります。

## 出典と検証

コピーしたDXF・STLは元ファイルとSHA-256が一致しています。DXFの単位と閉じた輪郭、STLの閉じたメッシュと正の体積を検査しました。元ファイル名・設計日・ハッシュと検査結果は [manifest.json](manifest.json) に記載しています。
